# claude-auto-log

One-command installer for Claude Code & Codex CLI auto logs and daily reports.

Claude Code & Codex CLI 自动日志 + 工作日报一键安装器。

Automatically records every conversation, code change, and token usage from your Claude Code / Codex CLI sessions, then generates a structured daily report with timeline.

---

## Features / 功能

- **Auto logging / 自动日志** — Captures conversations, code changes (Edit/Write/Bash), and token usage via Claude Code hooks
  通过 Claude Code hook 自动记录对话、代码变更（Edit/Write/Bash）和 token 消耗
- **Codex CLI support / Codex CLI 支持** — Same logging for OpenAI Codex CLI sessions
  OpenAI Codex CLI 会话同样支持自动日志
- **Daily report / 工作日报** — Generates a markdown daily report with timeline, project grouping, and statistics via Claude API
  通过 Claude API 生成带时间轴、按项目分组、含统计数据的 markdown 日报
- **Esc interrupt recovery / 中断补偿** — Missed interruptions are backfilled on next prompt
  用户 Esc 中断的对话会在下次发消息时自动补记
- **Logging toggle / 日志开关** — Pause/resume logging by creating/removing `.enabled` marker file
  通过创建/删除 `.enabled` 标记文件暂停/恢复日志记录
- **Cross-platform scheduler / 跨平台定时任务** — Windows Task Scheduler, macOS launchd, Linux crontab
  支持 Windows Task Scheduler、macOS launchd、Linux crontab

## Quick Start / 快速安装

```bash
npx claude-auto-log install --time 18:00
```

This will / 这会：
1. Copy logging scripts to `~/.claude/hooks/` / 复制日志脚本到 `~/.claude/hooks/`
2. Register a `Stop` hook in Claude Code settings / 在 Claude Code 设置中注册 `Stop` hook
3. Set up a daily scheduled task to generate reports at 17:55 / 注册定时任务在 17:55 生成日报

## Usage / 使用

```bash
# Install with daily report at 17:55 (5 min before specified time) / 安装并设置日报时间
npx claude-auto-log install --time 18:00

# Install without scheduler (manual reports only) / 只装插件不注册定时任务
npx claude-auto-log install --time 18:00 --no-scheduler

# Check installation status / 查看安装状态
npx claude-auto-log status

# Uninstall everything / 卸载
npx claude-auto-log uninstall
```

## What Gets Logged / 记录内容

Each conversation turn is recorded with / 每轮对话会记录：

- Timestamp and duration / 时间戳和耗时
- User question and Claude's response / 用户问题和 Claude 回答
- Code changes (Edit, Write, Bash file operations) with diff stats / 代码变更及 diff 统计
- Token usage (input / output / total) / Token 消耗（输入/输出/总计）

Logs are saved to / 日志保存路径：`~/.claude/cclogs/YYYY-MM-DD/<project-name>.md`

## Daily Report / 工作日报

The report is generated by sending your day's logs to Claude for summarization. It includes / 日报通过将当天日志发送给 Claude 进行总结，包含：

- Per-project statistics (files changed, time range, time spent, token usage) / 按项目统计（文件变更数、工作时段、时间投入、Token 消耗）
- Timeline-ordered work items with timestamps / 按时间顺序排列的工作条目，带时间标注
- Code change summary / 代码变更摘要
- Incomplete / in-progress items / 未完成/进行中的工作

Reports are saved to / 日报保存路径：`~/.claude/cclogs/YYYY-MM-DD/daily-report.md`

**Requirement / 前提条件：** Your `~/.claude/settings.json` must have `env.ANTHROPIC_AUTH_TOKEN` and `env.ANTHROPIC_BASE_URL` configured for report generation.
需要 `~/.claude/settings.json` 中配置好 `ANTHROPIC_AUTH_TOKEN` 和 `ANTHROPIC_BASE_URL` 才能生成日报。

## Toggle Logging / 日志开关

**By default, logging is PAUSED after installation.** You need to manually enable it by creating the `.enabled` marker file.

**安装后默认暂停记录。** 需要手动创建 `.enabled` 标记文件来开启日志。

**Enable (start logging) / 开启记录：**

```bash
# macOS / Linux / Git Bash
touch ~/.claude/cclogs/.enabled

# Windows PowerShell
New-Item "$env:USERPROFILE\.claude\cclogs\.enabled" -ItemType File -Force
```

**Disable (pause logging) / 暂停记录：**

```bash
# macOS / Linux / Git Bash
rm ~/.claude/cclogs/.enabled

# Windows PowerShell
Remove-Item "$env:USERPROFILE\.claude\cclogs\.enabled"
```
